# SMART ENERGY HOME — visor 3D (fase visual)

Gemelo digital web en Three.js. Esta fase no conecta Arduino ni muestra datos de sensores.

## Ejecutar en desarrollo

```bash
cd "/Users/luvigo/Desktop/Smart Energy Guardian/web3d"
npm install
npm run dev
```

Abre la URL que muestre Vite (por ejemplo `http://localhost:5173`).

## Build de producción

```bash
npm run build
npm run preview
```
